# Habit tracker app

This is a habit tracker app. You can write things you want to do every day, week, or month. Every day, you click whether you did them or not. The app should show your development using descriptions such as "good" or "could be better".

Build the project as a small web app using only HTML, CSS, and JavaScript. All data should be saved in the browser using `localStorage`. Do not use a server, database, frameworks, or a build step. The site will be hosted on GitHub Pages.

Run the app in a browser using `index.html`.

## Git workflow

The user is learning Git. Explain Git steps and wait for explicit permission before running them. Do not automatically commit, push, pull, merge, or delete branches.
